## 🎨 Customization Guide

### Change Colors
Edit `wwwroot/css/topbar.css`:
```css
:root {
    --primary-brown: #8B6F47;  /* Your color here */
    --primary-light: #A0826D;  /* Your color here */
}
```

### Add Pet Images
Edit `Views/Home/Index.cshtml`:
```html
<img class="hero-pet hero-pet-left"
     src="~/images/your-image.png"
     alt="Your pet" />
```

### Update Navigation
Edit `Views/Shared/_Layout.cshtml`:
```html
<li class="topbar-nav-item">
    <a class="topbar-nav-link" href="#section">Your Link</a>
</li>
```

### Update Button Text
Edit `Views/Home/Index.cshtml`:
```html
<a class="hero-btn">Your Text Here</a>
```
